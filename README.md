# Alura Plus

Landing page educacional baseada no Alura+, construída com HTML e CSS para praticar estruturação de páginas, composição visual e posicionamento de elementos.

[Ver projeto publicado](https://alura-plus-puce-sigma.vercel.app)

## Conteúdo

- Apresentação da oferta Combo+.
- Seções de benefícios e dispositivos compatíveis.
- Chamadas para assinatura.
- Rodapé com links institucionais.

## Tecnologias

HTML5, CSS3, CSS Grid, Flexbox e fontes do Google Fonts.

## Como executar

Clone ou baixe o repositório e abra `index.html` em um navegador. Não há dependências de aplicação ou etapa de build.

## Organização

- `index.html`: estrutura e conteúdo da página.
- `style.css`: estilos.
- `img/`: imagens e ícones.

## Escopo

Este projeto implementa a apresentação visual da página. Não inclui contratação de planos, processamento de pagamentos ou backend. Os links de assinatura e do rodapé são demonstrativos e precisam ser revisados antes de um uso real.

Projeto de estudo baseado no Alura+, da Alura. Marcas, textos e imagens pertencem aos respectivos titulares.
